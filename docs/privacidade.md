# Política de Privacidade — AutoFinance

Última atualização: 05/10/2026

AutoFinance é um aplicativo pessoal, de uso individual, mantido por seu próprio desenvolvedor. Esta política descreve quais dados do Google o app acessa e como os trata.

## Dados acessados

Com a sua autorização, o app acessa:

- **Gmail (somente leitura):** mensagens e anexos de faturas e boletos, para extrair valor e data de vencimento.
- **Google Calendar (eventos):** para criar e atualizar eventos de vencimento.

O app não envia, apaga nem altera e-mails. Não acessa contatos, arquivos do Drive nem outros serviços do Google.

## Como os dados são usados

Os dados são usados apenas para a função descrita acima, para o próprio dono da conta. Não são vendidos, compartilhados com terceiros nem usados para publicidade. O uso das informações recebidas das APIs do Google segue a [Política de Dados do Usuário dos Serviços de API do Google](https://developers.google.com/terms/api-services-user-data-policy), incluindo os requisitos de Uso Limitado.

## Armazenamento

O app guarda localmente apenas o token de autorização (refresh token) e os dados financeiros já extraídos, em um banco de dados sob controle do dono do app.
## Como revogar o acesso

Você pode revogar o acesso a qualquer momento em [myaccount.google.com/permissions](https://myaccount.google.com/permissions). Para pedir a exclusão dos dados guardados, abra uma issue em [github.com/rasecdev/AutoFinance/issues](https://github.com/rasecdev/AutoFinance/issues).

## Alterações

Esta política pode mudar. A data no topo indica a última atualização.
